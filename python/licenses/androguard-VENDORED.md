# Vendored from androguard 4.1.3

`python/androguard_rs/api_specific_resources/api_permission_mappings/permissions_*.json`
and `python/androguard_rs/api_specific_resources/aosp_permissions/permissions_*.json`
are copied unmodified from androguard 4.1.3
(`androguard/core/api_specific_resources/api_permission_mappings/` and
`.../aosp_permissions/`),
which is licensed under the Apache License, Version 2.0
(https://www.apache.org/licenses/LICENSE-2.0).

`core/src/axml_attrs.rs` (the system attribute id -> name table used to name
binary XML attributes) is generated by `scripts/gen_axml_attrs.py` from
androguard 4.1.3's `androguard/core/resources/public.xml` (AOSP data, also
Apache-2.0).

The Python modules `androguard_rs/apk.py`, `axml.py`, `misc.py`, `dex.py`,
`api_specific_resources/__init__.py` and `core/androconf.py` port parts of
androguard 4.1.3 (`androguard/core/apk/__init__.py`,
`androguard/core/axml/__init__.py`, `androguard/misc.py`,
`androguard/core/dex/__init__.py` (`get_type()`, `get_information()`),
`androguard/core/api_specific_resources/__init__.py`,
`androguard/core/androconf.py`), Apache-2.0;
their changes are described in each module's docstring.

`androguard_rs/_arscconfig.py` is androguard 4.1.3's `ARSCResTableConfig`
class and the configuration constants it uses
(`androguard/core/axml/__init__.py`), copied with its debug logging
dropped, Apache-2.0. `androguard_rs/_agerr.py` reproduces androguard
4.1.3's `TypeMapItem` and `HiddenApiClassDataItem` flag enums
(`androguard/core/dex/dex_types.py`, `androguard/core/dex/__init__.py`), so
load errors carry androguard's messages.
